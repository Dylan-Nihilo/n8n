# 更新说明 v2.2

## 🎯 重大重构：模块化拆分

### 更新日期
2025-12-31

### 核心变更
将内容创作和发布功能按平台完全拆分，实现更细粒度的模块化设计。

---

## 📦 工作流变更

### 删除（3个旧工作流）
- ❌ `content-generate-ai.json` - 合并的内容生成工作流
- ❌ `content-with-images.json` - 合并的内容+配图生成工作流
- ❌ `publish-xiaohongshu.json` - 旧的小红书发布工作流

### 新增（4个新工作流）

#### 1. 小红书-内容创作 (`xiaohongshu-content-create.json`)
**功能**：专门为小红书平台创作内容
- 触发：周一三五9点自动执行
- 流程：素材+产品 → AI生成标题 → AI生成正文 → AI生成配图描述 → Nano Banana生成9张图 → 写入Notion
- 特点：
  - 小红书风格（口语化、emoji、年轻化）
  - 800-1200字正文
  - 9张配图（封面+产品+氛围+知识）
  - 小红书专用话题标签

#### 2. 公众号-内容创作 (`wechat-content-create.json`)
**功能**：专门为公众号平台创作内容
- 触发：周二四10点自动执行
- 流程：素材+产品 → AI生成标题 → AI生成正文 → AI生成配图描述 → Nano Banana生成3张图 → 写入Notion
- 特点：
  - 公众号风格（专业、有深度、有洞察）
  - 2000-3000字正文
  - 3张配图（封面+内容+产品）
  - 公众号专用话题标签

#### 3. 小红书-发布 (`xiaohongshu-publish.json`)
**功能**：准备小红书发布内容
- 触发：手动触发
- 流程：读取已审核内容 → 格式化 → 生成发布指南 → 更新Notion状态
- 特点：
  - 自动添加话题标签（#格式）
  - 提供详细发布指南
  - 需人工完成实际发布

#### 4. 公众号-发布 (`wechat-publish.json`)
**功能**：准备公众号发布内容
- 触发：手动触发
- 流程：读取已审核内容 → 格式化 → 生成发布指南 → 更新Notion状态
- 特点：
  - 自动添加版权声明
  - 提供多种发布方式（后台/第三方工具）
  - 需人工完成实际发布

---

## 🎯 设计优势

### 1. 职责单一
- 每个工作流只负责一个平台的一个功能
- 易于理解、维护、调试

### 2. 灵活组合
- 可以单独运行任何一个工作流
- 可以自由组合成完整流程
- 可以独立优化每个环节

### 3. 平台差异化
- 小红书：口语化、短内容、多图、年轻化
- 公众号：专业化、长内容、少图、深度化
- 各平台独立优化，不互相影响

### 4. 易于扩展
- 添加新平台只需新增工作流
- 不影响现有工作流
- 例如：可以轻松添加抖音、知乎、B站等

## 🔄 使用流程

### 完整自动化流程

```
【自动】热点抓取（每6小时）
    ↓
【人工】在Notion筛选热点
    ↓
【自动】小红书内容创作（周一三五9点）
【自动】公众号内容创作（周二四10点）
    ↓
【人工】在Notion审核内容
    ↓
【手动】触发小红书发布工作流
【手动】触发公众号发布工作流
    ↓
【人工】按指南发布到平台
    ↓
【人工】在Notion记录发布信息
    ↓
【自动】数据监测（每6小时）
```

### MVP流程（最简单）

```
1. 手动触发 trend-multi-source → 获取热点
2. 手动触发 xiaohongshu-content-create → 生成小红书内容
3. 手动触发 xiaohongshu-publish → 准备发布
4. 人工发布到小红书
```
